# 마이페이지 (`/me`) 화면 정의

> 기준본(와이어프레임 v2.1 · 피그마 7화면)에 없던 화면 - 2026-09-19 신설, 같은 날 밤 재설계. 이 문서가 기준 역할
> 구현: ondal-FE `src/pages/MyPage.tsx` · 테마 미리보기 `src/components/code/CodeMirrorPane.tsx`(`EditorThemeGalleryImpl`)

## 1. 목적·진입

- 목적: 내가 누구로 로그인했는지, 지금까지 무엇을 했는지, 어디 소속인지 한 화면에서 확인 + 개인 설정(코드 에디터 테마)
- 진입: `AppShell` 상단 바 우측 아바타·이름 클릭. HOJ 모드 상단 바에는 없음 - 모드 전환 확인 팝업을 우회하지 않기 위해
- 대상: 로그인한 누구나(`@LoginOnly`). 승인 대기(PENDING) 계정은 `PendingApprovalPage` 가 대신 그려지므로 이 화면에 오지 않음

## 2. 구성 (위에서 아래로) - 홈 대시보드와 같은 문법

| 구역 | 내용 | 데이터 | 비고 |
|---|---|---|---|
| 헤더 | 아바타(홈페이지 구글 프로필 사진, 없으면 이름 첫 글자 - [결정 14](../decisions/14-%ED%94%84%EB%A1%9C%ED%95%84-%EC%82%AC%EC%A7%84-%ED%99%88%ED%8E%98%EC%9D%B4%EC%A7%80-%EA%B5%AC%EA%B8%80-%ED%94%84%EB%A1%9C%ED%95%84-%EC%97%B0%EB%8F%99.md)) · 이름 · 직책 | `GET /api/auth/me` + `GET /api/me/cohorts` | 직책 = 전역 역할 표시명(해구르르·관리자) > 교육운영진(`canManage` 분반 있음) > 부원. 버튼 없음 - 로그아웃은 사이드바 |
| 활동 KPI 4장 | 과제 제출 N건 · HOJ 연습 제출 N건 · 맞힌 문제 N개 · 소속 분반 N개(지난 M개) | `GET /api/me/stats` · `/api/me/cohorts` | 홈 `StatCard` 재사용. 홈은 현재 분반 기준, 여기는 가입 후 누적. 값은 서버 그대로 - 재제출 포함, 맞힌 문제 = 과제·연습 어느 쪽이든 1회 이상 정답 |
| 내 정보 (1/3) | 이름 · 로그인 아이디 · 가입일(KST 날짜) | `/api/auth/me` · `stats.joinedAt` | 라벨 폭 고정 2열 표. 수정 UI 없음 - 홈페이지(Keycloak)가 원본, 안내 한 줄 |
| 코드 에디터 테마 (2/3) | 테마 5개(기본 · GitHub Light · One Dark · Dracula · Solarized Light) 카드 - 카드마다 같은 파이썬 5줄을 그 테마로 그린 미리보기 + 라디오 | 브라우저 `localStorage` `ondal-editor-theme` | 서버 저장 없음(취향 설정). 고르면 즉시 모든 에디터(제출 폼 · 정답 코드 · 열람)에 반영. 미리보기는 읽기 전용 - 초점·드래그 안 걸림(`aria-hidden`, `tabindex -1`) |
| 소속 분반 (전체 폭) | 분반명(링크) + 직책 배지 + 보관됨 배지, "내 수업으로" 링크 | `/api/me/cohorts` (ACTIVE 먼저) | 배지는 `CohortCard` 와 동일. 보관 분반은 흐리게. 미소속이면 안내 문장 |

## 3. 상태

| 상태 | 표시 |
|---|---|
| 로딩(분반·활동 중 하나라도) | `LoadingScreen` "내 정보 불러오는 중..." |
| 오류 | `ApiErrorView`(재시도) - 401 은 공통 처리로 로그인 화면 |
| 미소속 | 소속 분반 패널에 "아직 소속된 분반이 없어요..." / KPI 소속 분반 0개 |
| 테마 미리보기 로딩 | 에디터 번들 지연 로딩 동안 스켈레톤 "테마 미리보기 불러오는 중..." |

## 4. 하지 않는 것

- 이름 · 아이디 · 비밀번호 변경: 홈페이지(Keycloak) 소관
- 점수 · 랭킹: P3 티어 이전
- 알림 설정: 알림 자체가 없음(2026-09-14 확정)
- 로그아웃 버튼: 사이드바 · HOJ 상단 바에 있음

## 5. 디자인 규칙 적용 (FE `CLAUDE.md` 디자인 규칙)

- 헤더 `border-b pb-2.5` + `h1 text-2xl` / 패널 `bg-card border rounded-lg p-4` + `h2 text-base font-bold` / KPI 는 `StatCard` - 페이지 전용 부품 없음
- 키-값 표는 `dl grid-cols-[6rem_1fr]` 왼쪽 정렬 - 라벨과 값을 양 끝으로 벌리지 않음
- 반응형: KPI `sm` 2열 → `xl` 4열, 본문 그리드 `lg` 1:2, 테마 카드 `sm` 2열 → `xl` 3열, 그 아래는 전부 1열
- 푸터: 셸이 화면 맨 아래에 고정(FE 디자인 규칙 "푸터 고정") - 페이지는 푸터를 그리지 않음

- 2026-09-19 밤: 재설계(FE #80) - PM "지금 디자인과 다르고 시각적으로 이상하다" → 홈 문법으로 재구성. 활동 타일 → `StatCard`, 키-값 왼쪽 정렬, 로그아웃 · 상태 행 제거, 테마 셀렉트 → 미리보기 카드(PM 요청: 각 테마가 어떤 변화를 주는지 보여줄 것), 푸터 하단 고정(PM 요청: 페이지마다 위치가 제각각)
