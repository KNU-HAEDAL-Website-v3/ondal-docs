## 1. 화면 매핑

- 과제 목록(피그마 28:1317) · 과제 상세(28:1433)의 `SAMPLE_*` → #13(목록)·#14(단건)으로 교체 대상
- 등록·수정·삭제 UI 진입은 `canManage`(분반 응답 필드)로 분기 - 과제 API 응답에 별도 권한 필드 없음
- 보관 분반: `status == ARCHIVED`면 쓰기 UI 사전 비활성 (409 COHORT_ARCHIVED 규약)

## 2. 표시 규칙

- 문제 번호: 목록·상세에서 제목 앞 `#1000` 형식 표시 (2026-08-27, design.md 결정 7). 등록 폼 번호 필드는 "비우면 자동 부여" 안내, 수정 폼에서 번호 변경 시 확인 문구("문제 번호를 바꾸면 학생이 혼동할 수 있어요")
- 마감 표시: `dueAt`(UTC)을 FE가 KST로 변환 표시 (FE CLAUDE.md 규칙 4)
- D-day 문구: dueAt 기반 표시 가공 - 허용
- 제출/미제출/지각 **배지**: 제출 슬라이스 전까지 표시 불가 - 서버 판정값이 아직 없고 프론트 재계산은 금지 (FE CLAUDE.md 규칙 4)
- 목록 정렬·그룹핑: 서버 기본 = 차시 오름차순(차시 없음 마지막) → 등록순. 차시 그룹 헤더는 `sessionNo`로 구성(NULL은 "기타" 등으로 표시), D-day순 등 다른 정렬 옵션은 FE 재정렬 (P1 페이징 없음, 전체 목록 수신)

- P1 상세는 title·description·dueAt 표시까지 - description은 문제 링크 포함 자유 텍스트
