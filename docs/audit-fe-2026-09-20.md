## 4. 남은 것

### BE·API 가 있어야 하는 것 (B)

- 심화 과제: 링크+파일+메모 묶음 제출, 제출 메모 필드, 파일 종류(PDF·PPTX)·용량(50MB) 확대
- 분반 기간·주차("진행: 2주차 / 총 8주"), 분반 전체 미제출 합계, 분반 최근 제출 피드(실시간 채점 현황)
- 관리자: 오늘 제출 · 채점 대기 · 평균 채점 시간 · Judge/DB 상태 · 감사 로그
- 공지: 예약 게시 · 서버 초안 · 파일 첨부 · 다중 수신 대상 · 조회수 · 유형 분류
- 현황판 응답에 loginId(학번 표시)

### FE 후속 (A, 이번 범위 밖)

- 학생 홈: ACTIVE 분반 여러 개 통합 집계(`useQueries`)
- 출석 관리: 수강생 × 차시 매트릭스 탭, 검색 · 상태 필터, 헤더 우측 주 액션 정리
- 공지: 본문 마크다운 렌더(단일 줄바꿈 보존을 위해 `remark-breaks` 필요) · 미리보기, 작성 폼 2단
- 공통: `PageHeader` · 표 헤더 클래스 통일(3종 혼재), 부제 앞 아이콘, 태그 관리 뒤로가기 제거, HOJ 목록 제목
- 목록 하단 "총 N건"을 과제 · HOJ 목록에도

### PM 결정 필요 (C)

- 차시 단위 현황(수강생 × 그 차시 과제들 매트릭스) 신설 여부 → 도입 시 차시 현황 API
- 사이드바 활성 항목을 원안 틴트로 되돌릴지
- 홈 좌우 배치(원안 공지 좌 · 과제 우) - 현재는 과제 우선 배치 유지 권장
