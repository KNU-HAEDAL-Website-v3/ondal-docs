## 1. 범위

- **차시(Session)** CRUD 4개 + **출석(Attendance)** 3개 = API 7개 (`attendance` 패키지)
- 운영진이 차시(번호·날짜·제목)를 만들고, 차시별로 수강생 명단에 출석 / 지각 / 결석을 표시. 학생은 자기 기록과 출석률을 봄
- 범위 밖: 학생 셀프 체크인(QR·코드), 출석 시간 자동 기록, 엑셀 내보내기, 지각 N회 = 결석 환산, 사유 메모, 알림. FE 견본(피그마 28:1013)의 "출석 시간 08:55 AM"·"기수/반 필터"·"출석부 다운로드"·페이지네이션은 구현하지 않음

## 2. 결정

1. **Session 엔티티 도입 - 부분 승격** - `sessions(cohort_id, session_no, title, held_on)`. 차시가 처음으로 고유 속성(날짜)을 갖게 되므로 테이블로 만든다(결정 6 의 재검토 조건 충족)
   - **`assignments.session_no` 는 정수 그대로 두고 FK 를 걸지 않는다** - P1 과제 API·화면·테스트(차시 블럭·프리필)를 흔들지 않기 위함. 과제와 차시는 같은 번호로 느슨히 대응. FK 승격은 "차시 없는 과제 금지" 같은 요구가 생길 때 재검토
2. **출석 상태 3종 = PRESENT(출석) / LATE(지각) / ABSENT(결석)** - "미확인"은 상태가 아니라 **기록 없음**(응답 `status: null`). 판정하지 않은 학생을 결석으로 오해하지 않게
3. **표시는 운영진이 한다 (셀프 체크인 없음)** - decisions/4 의 "오프라인 출석" 전제. 학생은 읽기만. 기록에는 표시한 운영진(`checked_by`)과 시각(`checked_at`)을 남긴다
4. **표시 API = 차시 단위 일괄 upsert** - `PUT .../sessions/{id}/attendances { records: [{loginId, status}] }`. 한 명 바꾸기도 원소 1개짜리 목록, "일괄 출석 처리"는 미확인 전원을 PRESENT 로 보내는 목록. `status: null` 은 기록 삭제(미확인으로 되돌림). 응답은 갱신된 **차시 명부 전체**(재조회 불필요 - 수강생 배정 API 선례)
5. **명부의 행 = 현재 STUDENT 소속 명단(이름순)** - 운영진은 행에 없다(현황판 선례). 표시 대상이 이 분반의 수강생이 아니면 404 `해당 분반의 수강생이 아닙니다`. 배정 해제된 학생의 과거 기록은 남지만 명부에는 안 보인다
6. **출석률 = 출석 ÷ 판정된 차시(출석 + 지각 + 결석) × 100, 정수 반올림** - 지각은 출석률에 넣지 않고 횟수로 따로 보여 준다(정시 출석 비율). 판정된 차시가 없으면 `null`(FE "-"). 서버 계산값 - 프론트 재계산 금지(CLAUDE.md 규칙 4). 정책이 바뀌면(지각 인정 등) 서버 한 곳만 고침
7. **차시 번호는 분반 안에서 유일** - `uk_sessions_cohort_no`. 등록 시 비우면 자동(현재 최대 + 1, 없으면 1), 지정하면 그 번호(중복 409 CONFLICT). 과제의 `session_no` 와 같은 번호 체계
8. **`held_on` 은 날짜(date, KST 달력일)** - 수업일은 시각이 아니라 날짜. 다른 열(UTC timestamp)과 다른 타입을 쓰는 유일한 곳. 응답 `"2026-09-14"`
9. **차시 삭제 = 그 차시 출석 기록 연쇄 삭제(서비스)** - 기록 수를 응답에 실어 FE 가 경고("출석 기록 N건이 함께 삭제") 후 삭제
10. **보관 분반: 차시·출석 열람 유지, 쓰기 409 `COHORT_ARCHIVED`** - `ensureActive()` 규약
11. **조회 스코프** - 차시는 `(id, cohort_id)` 로 조회, 불일치·부재 404 (하위 리소스 규약). 학생의 `/attendances/me` 는 요청자 자신의 기록만
12. **인덱스** - `sessions (cohort_id, held_on)`, `attendances (user_id)` + 유니크 `(session_id, user_id)`
13. **시더** - 진행 중 분반에 차시 2개(1차시 10일 전, 2차시 3일 전) + 기록 5건(1차시 출석·지각·결석, 2차시 출석 2·미확인 1). FE mock 동일
