## 0. 준비

- 계정·역할 준비(PM): 관리자 승격(SQL 1회) → 관리자 화면에서 테스트 분반 생성 → 운영진 지정 → 수강생 배정(명단 붙여넣기)
- 역할 3종을 각각 1명 이상: 해구르르(전역 ADMIN) / 교육운영진(분반 OPERATOR) / 수강생(분반 STUDENT). 한 사람이 브라우저 2개(시크릿 창)로 역할을 바꿔도 됨
- 결과 기록: 항목마다 ✅ / ❌ + 한 줄 메모. ❌ 는 6절 형식으로 보고

## 1. 공통 (모든 역할)

- [ ] 로그인 버튼 → 홈페이지 로그인 → Ondal 로 돌아옴, 우상단에 내 이름 표시
- [ ] Sign Out → 홈페이지 세션까지 종료, 다시 들어가면 로그인 화면
- [ ] 홈: 소속 분반 카드 / 미소속이면 안내 문구 (숫자가 실제 데이터와 맞는지)
- [ ] 사이드바 메뉴 전부 이동됨: 홈 · 출석 · 문제(준비 중 안내) · 과제 · 내 수업 · 공지사항 · (관리자만) 분반 관리 · 도움말
- [ ] 세션 만료 상황: 다른 탭에서 Sign Out 한 뒤 작성 중이던 글을 저장 → 로그인 화면 → 다시 로그인 → **원래 화면으로 돌아오고 입력 내용이 남아 있음** (질문·답변·공지·코멘트 폼)
- [ ] 없는 주소(`/cohorts/999`) → "찾을 수 없음" 안내, 화면이 깨지지 않음
- [ ] 모바일 폭(태블릿·휴대폰)에서 표가 가로 스크롤로 보이고 본문은 잘리지 않음

## 2. 해구르르 (관리자)

- [ ] 분반 관리 → 분반 생성(이름·기간) → 목록에 보임
- [ ] 분반 수정 → 이름 변경 반영
- [ ] 운영진 지정·해제 - 지정된 사람이 로그인하면 운영진 화면(현황판·출석 표시)이 보임
- [ ] 명부 → 학번/아이디 명단 붙여넣기 배정 → 없는 아이디는 오류 안내, 있는 아이디는 배정됨
- [ ] 수강생 제외 → 그 학생 로그인 시 분반이 안 보임 (제출 기록은 서버에 남음)
- [ ] 분반 **보관** → 소속자 화면에 "보관" 표시, 새 제출·질문·공지 작성 버튼 사라짐, 열람은 됨 → **복원** → 다시 작성 가능
- [ ] 전체 공지 작성(필독 체크) → 모든 사용자 공지 목록 맨 위에 필독 표시로 보임 / 수정 / 삭제

## 3. 교육운영진

- 과제
  - [ ] 과제 등록(제목·설명·차시·마감·문제 번호 자동 채번) → 학생 목록에 보임
  - [ ] 과제 수정(마감 변경) → 학생 배지 상태가 바뀔 수 있음 확인 / 과제 삭제 → "제출물 N건 함께 삭제" 경고
  - [ ] 현황판: 수강생 전원이 행으로(미제출 포함), 상태·횟수·최근 제출·**코멘트 열(남김/아직)**
  - [ ] 열람(눈 아이콘) → 최신 제출의 코드/파일 다운로드/링크 확인
  - [ ] **코멘트 남기기** → 학생 화면에 보임 / 수정(덮어쓰기) / 지우기(확인 창) - 점수 입력란이 없는 것이 정상
  - [ ] 학생이 재제출하면 현황판 코멘트 열이 "아직"으로 돌아옴
- 공지·Q&A
  - [ ] 분반 공지 작성·수정·삭제 → 그 분반 소속자에게만 보임. 전체 공지 작성 버튼은 없음(관리자 전용)
  - [ ] Q&A: 학생 질문에 답변 → 목록 행의 "답변 N" 증가 / 남의 질문·답변 삭제 가능, 남의 글 수정은 불가
- 출석
  - [ ] 출석 → 분반 선택 → 차시 등록(회차·제목·날짜) → 명부에 출석/지각/결석 표시 → 학생 화면 출석률 반영
  - [ ] 차시 수정·삭제(삭제 시 그 차시 기록도 삭제 경고)

## 4. 수강생

- [ ] 과제 목록: 배지(미제출/제출/제출(추가)/지각)와 D-day 가 맞음
- [ ] 제출 3종: 코드 붙여넣기(+언어 선택) / zip 업로드(10MB 이하, zip 외 확장자는 거부) / 링크 1~5개
- [ ] 마감 후 제출 → "지각 제출로 기록" 안내 후 제출됨, 배지 지각
- [ ] 재제출 → 내 제출 기록에 순번대로 쌓임(최신 표시), 행 펼치면 코드 전문·다운로드
- [ ] 운영진이 남긴 코멘트: 행에 "코멘트" 배지 → 펼치면 작성 운영진·시각·내용 (수정 버튼 없음)
- [ ] 다른 학생 제출물은 어떤 경로로도 볼 수 없음 (주소 직접 입력 시 "찾을 수 없음")
- [ ] 출석: 내 출석 현황·출석률만 보임(다른 학생 없음)
- [ ] 공지: 전체 공지 + 내 분반 공지만 보임, 작성 버튼 없음
- [ ] Q&A: 질문 작성·수정·삭제(내 글만) / 답변 작성 / 내 답변 수정·삭제, 남의 답변에는 버튼 없음
- [ ] 보관된 분반(지난 학기)이 "지난 소속"으로 보이고 기록 열람만 됨
