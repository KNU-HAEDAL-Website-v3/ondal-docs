# 테스트 주간 체크리스트 (2026-09-19 ~ 09-25)

> 부트캠프 시작(9/28) 전, 운영진·해구르르가 **운영 서버**에서 실제 계정으로 화면을 훑는 체크리스트
> 작성 2026-09-14 · **갱신 2026-09-15** - 그 사이 자동 채점 운영 가동, HOJ(문제 라이브러리·풀이·채점)·태그 도입, 과제 등록이 "문제 배정"으로 바뀜

## 0. 준비

- 접속: `https://ondal.haedal-sos-man-in-the-mirror.com` - 홈페이지(Keycloak) 계정으로 로그인
- 계정·역할 준비(PM): 관리자 승격(SQL 1회) → 관리자 화면에서 테스트 분반 생성 → 운영진 지정 → 수강생 배정(명단 붙여넣기 또는 부원 목록에서 선택)
  - ※ 2026-09-19 승인 게이트([결정 10](decisions/10-%EC%8A%B9%EC%9D%B8-%EA%B2%8C%EC%9D%B4%ED%8A%B8-%EC%B2%AB-%EB%A1%9C%EA%B7%B8%EC%9D%B8%EC%9D%80-%EC%8A%B9%EC%9D%B8-%EB%8C%80%EA%B8%B0.md)): 홈페이지(구글)로 처음 로그인한 계정은 **승인 대기** 화면만 보임 - 운영진이 `부원 관리`에서 승인하거나 분반에 배정해야 열림. 명단으로 먼저 배정해 둔 아이디는 로그인 즉시 열림
- 역할 3종을 각각 1명 이상: 해구르르(전역 ADMIN) / 교육운영진(분반 OPERATOR) / 수강생(분반 STUDENT). 한 사람이 브라우저 2개(시크릿 창)로 역할을 바꿔도 됨
- **데이터 준비(운영진)**: 태그 2~3개(관리자) → HOJ 에 문제 2개 출제(하나는 테스트케이스 있음, 하나는 없음) → 그중 하나를 과제로 배정
- 결과 기록: 항목마다 ✅ / ❌ + 한 줄 메모. ❌ 는 7절 형식으로 보고

## 1. 공통 (모든 역할)

- [ ] 로그인 버튼 → 홈페이지 로그인 → Ondal 로 돌아옴, 우상단에 내 이름 표시
- [ ] **이름이 "성이름" 순서로 보임** (김철수 O / 철수 김 X) - 2026-09-15 수정분
- [ ] **로그아웃**(영문 `Sign Out` 아님) → 홈페이지 세션까지 종료, 다시 들어가면 로그인 화면
- [ ] 홈: 소속 분반 카드 / 미소속이면 안내 문구 (숫자가 실제 데이터와 맞는지)
- [ ] **첫 로그인(승인 대기)**: 한 번도 배정된 적 없는 구글 계정으로 로그인 → 사이드바 없는 "승인을 기다리고 있어요" 화면(이름·로그인 아이디 표시) → 주소를 직접 쳐도(`/assignments`, `/problems`) 같은 화면 → 운영진이 승인하면 "승인됐는지 다시 확인" 으로 바로 홈
- [ ] 사이드바 메뉴 전부 이동됨: 홈 · 출석 · 과제 · 내 수업 · **Q&A** · 공지사항 · (관리자만) 분반 관리 · 아래쪽에 **HOJ로 이동하기** · 도움말
  - ※ 본문 목록에 "문제" 항목은 없음 - HOJ 진입은 도움말 바로 위. **태그 관리는 HOJ 모드의 상단 메뉴**에 있음 (2026-09-19, 결정 9)
- [ ] 세션 만료 상황: 다른 탭에서 로그아웃 한 뒤 작성 중이던 내용을 저장 → 로그인 화면 → 다시 로그인 → **원래 화면으로 돌아오고 입력 내용이 남아 있음**
  - 대상 폼: 질문 · 답변 · 공지 · 코멘트 · 분반 · **과제 제출(코드)** · **문제 출제** · **HOJ 풀이**
- [ ] 없는 주소(`/cohorts/999`, `/problems/999`) → "찾을 수 없음" 안내, 화면이 깨지지 않음
- [ ] 권한 밖 주소 직접 입력: 수강생이 `/admin/tags`, `/problems/new`, `/problems/1/edit` → **홈으로 돌아감**
  - 폼이 열렸다가 저장할 때야 "권한 없음"이 뜨면 ❌
- [ ] 모바일 폭(태블릿·휴대폰)에서 표가 가로 스크롤로 보이고 본문은 잘리지 않음
- [ ] 코드가 보이는 곳(제출·HOJ)에서 **테마 드롭다운**으로 One Dark 등을 고르면 모든 코드 영역이 함께 바뀌고, 새로고침해도 유지됨

## 2. 해구르르 (관리자)

- [ ] 분반 관리 → 분반 생성(이름·기간) → 목록에 보임
- [ ] 분반 수정 → 이름 변경 반영
- [ ] 운영진 지정·해제 - 지정된 사람이 로그인하면 운영진 화면(현황판·출석 표시)이 보임
- [ ] 명부 → 학번/아이디 명단 붙여넣기 배정 → 없는 아이디는 오류 안내, 있는 아이디는 배정됨
- [ ] 수강생 제외 → 그 학생 로그인 시 분반이 안 보임 (제출 기록은 서버에 남음)
- [ ] 분반 **보관** → 소속자 화면에 "보관" 표시, 새 제출·질문·공지 작성 버튼 사라짐, 열람은 됨 → **복원** → 다시 작성 가능
- [ ] 전체 공지 작성(필독 체크) → 모든 사용자 공지 목록 맨 위에 필독 표시로 보임 / 수정 / 삭제
- **태그 관리** (2026-09-15 신설)
  - [ ] 태그 추가 → HOJ 목록 필터와 문제 출제 화면의 선택지에 바로 나타남
  - [ ] 태그 이름 수정 → 그 태그가 붙은 **문제 쪽 표시도 함께** 바뀜
  - [ ] 쓰는 문제가 있는 태그 삭제 → **거부 + "먼저 문제에서 태그를 떼세요"** 안내
  - [ ] 아무 문제도 안 쓰는 태그 삭제 → 삭제됨
- 문제 가져오기 (2026-09-19 신설, 문제 은행 번들 - [결정 11](decisions/11-%EB%AC%B8%EC%A0%9C-%EC%9D%80%ED%96%89-%EB%82%9C%EC%9D%B4%EB%8F%84-%ED%97%88%EC%9A%A9-%EC%96%B8%EC%96%B4-%EB%B2%88%EB%93%A4-%EA%B0%80%EC%A0%B8%EC%98%A4%EA%B8%B0.md))
  - [ ] HOJ → "문제 가져오기" → 위쪽 "깃허브에서 가져오기"에 `KNU-HAEDAL-Website-v3/ondal-problems@main` 표시 → **main 가져오기** → 몇 초 뒤 **추가 150 · 갱신 0 · 건너뜀 0 · 새 태그: … · 커밋 SHA** 결과 (서버 `.env` 에 `PROBLEM_BANK_GITHUB_TOKEN` 필요. 없으면 "토큰이 없어요" 안내와 함께 아래 파일 업로드만 가능)
  - [ ] 다시 누르면 **건너뜀 150**, "덮어쓰기" 체크 시 갱신 150 (재채점 없음)
  - [ ] (보조) 파일 업로드: `bank.json` 선택 → "15번에 나눠 보내요" → "묶음 n/15 보내는 중" 진행 → 같은 결과
  - [ ] 문제 목록에 **난이도 열**(예 2-3)과 대분류 필터, 언어 특화 문제에 "C 전용" 칩. C 전용 문제는 제출 언어 선택지가 C 뿐이고 다른 언어로 보내면 400
  - [ ] 문제 목록 **정렬**(번호 오름/내림 · 난이도 낮은/높은 순 · 안 푼 문제 먼저 · 출제 많은 순)과 "N문제" 건수. 검색창에 "DP" 를 치면 **태그 이름**으로도 찾아짐. 태그는 많이 쓰인 20개 + 문제 수만 보이고 "태그 이름으로 찾기" · "태그 모두 보기 (92)" 로 나머지 (FE #78)
  - [ ] 표본 확인: 2001(두 수의 합) Python·C 정답 제출 → 맞았습니다 / 2077(외판원) Python 정답 → 시간 제한 안에 맞았습니다
  - [ ] 운영진 계정에는 태그 관리 메뉴가 **안 보임**

## 3. 교육운영진

- 문제 출제 (HOJ, 2026-09-15 신설)
  - [ ] HOJ → "문제 출제" → 제목·본문·**태그 선택** → 번호를 비우면 **자동 채번**(#1000부터)
  - [ ] 자동 채점 켜기 → 테스트케이스 표에 입력·기대 출력 입력
  - [ ] **정답 코드로 기대 출력 채우기** → 실행 결과가 기대 출력 칸에 들어옴 (저장은 별도)
  - [ ] **출제 검증** → 정답 코드가 모든 케이스를 통과하는지 확인됨
  - [ ] 기대 출력이 빈 행이 있으면 **경고 + 저장 직전 확인 창** (비운 채 저장하면 모든 제출이 오답이 됨)
  - [ ] 저장 후 문제 상세로 이동, 태그·제한·번호가 그대로
  - [ ] 문제 수정 → 테스트케이스를 바꾸면 **"이 문제로 채점된 제출 N건 다시 채점할까요?"** 확인
  - [ ] 배정된 과제가 있는 문제 삭제 → **거부 안내**(과제를 먼저 지워야 함)
- 과제 (V7 이후 = **문제 배정**)
  - [ ] 과제 등록 → "1. 문제 고르기"에서 HOJ 문제 선택 → "2. 차시와 마감" → 배정됨
    - ※ 과제 화면에는 이제 제목·설명 입력란이 **없음**(문제의 것) - 있으면 ❌
  - [ ] 목록에서 문제를 번호·제목으로 검색해 고를 수 있음 / "새 문제 출제" 링크로 HOJ 출제 화면 이동
  - [ ] 과제 상세에 **문제 제목·태그 + "HOJ 에서 이 문제 보기"** 링크
  - [ ] **같은 문제를 다른 분반에도 배정** → 양쪽에서 같은 문제로 보이고, 테스트케이스를 한쪽에서 고치면 **양쪽 판정이 함께** 갱신됨
  - [ ] 과제 수정(마감 변경) → 학생 배지 상태가 바뀔 수 있음 확인
  - [ ] 과제 삭제 → "제출물 N건 함께 삭제" 경고 → 삭제 후에도 **HOJ 의 그 문제는 그대로 남아 있음**
  - [ ] 현황판: 수강생 전원이 행으로(미제출 포함), 상태·횟수·최근 제출·**코멘트 열**·**판정 열**
  - [ ] 열람(눈 아이콘) → 최신 제출의 코드/파일 다운로드/링크 확인
  - [ ] **코멘트 남기기** → 학생 화면에 보임 / 수정(덮어쓰기) / 지우기(확인 창) - 점수 입력란이 없는 것이 정상
  - [ ] 학생이 재제출하면 현황판 코멘트 열이 "아직"으로 돌아옴
  - [ ] **재채점** → 이 과제의 코드 제출이 다시 채점됨(다른 분반 제출은 건드리지 않음)
- 공지·Q&A
  - [ ] 분반 공지 작성·수정·삭제 → 그 분반 소속자에게만 보임. 전체 공지 작성 버튼은 없음(관리자 전용)
  - [ ] 사이드바 **Q&A** → 분반 고르기(분반이 하나면 바로 이동) → 학생 질문에 답변 → 목록 행 "답변 N" 증가
  - [ ] 남의 질문·답변 삭제 가능, 남의 글 수정은 불가
- 출석
  - [ ] 출석 → **"1. 분반"에서 분반 선택**(분반이 하나여도 선택 줄이 보임) → "2. 차시" 선택
  - [ ] 차시 등록(회차·제목·날짜) → 명부에 출석/지각/결석 표시 → 학생 화면 출석률 반영
  - [ ] **명부 정렬** 이름순 / 상태순(미확인 먼저) / 학번순 - **출석을 표시해도 행이 위아래로 튀지 않음**
  - [ ] **이 차시 내보내기** → CSV 가 엑셀에서 한글 안 깨지고 열림
  - [ ] **분반 전체 내보내기** → 가로 = 차시, 세로 = 수강생, 끝에 출석/지각/결석/출석률
  - [ ] 차시 수정·삭제(삭제 시 그 차시 기록도 삭제 경고)

## 4. 수강생

- 과제
  - [ ] 과제 목록: 배지(미제출/제출/제출(추가)/지각)와 D-day 가 맞음
  - [ ] 제출 3종: 코드 붙여넣기(+언어 선택) / zip 업로드(10MB 이하, zip 외 확장자는 거부) / 링크 1~5개
  - [ ] **자동 채점 문제**: 코드 제출 직후 "채점 중" → 잠시 뒤 **맞았습니다/틀렸습니다** 판정으로 바뀜
  - [ ] 판정을 펼치면 케이스별 결과 - **공개 케이스만** 입력·기대 출력·실제 출력이 보이고 비공개는 판정만
  - [ ] 마감 후 제출 → "지각 제출로 기록" 안내 후 제출됨, 배지 지각
  - [ ] 재제출 → 내 제출 기록에 순번대로 쌓임(최신 표시), 행 펼치면 코드 전문·다운로드
  - [ ] 운영진이 남긴 코멘트: 행에 "코멘트" 배지 → 펼치면 작성 운영진·시각·내용 (수정 버튼 없음)
  - [ ] 다른 학생 제출물은 어떤 경로로도 볼 수 없음 (주소 직접 입력 시 "찾을 수 없음")
- 그 밖
  - [ ] 출석: 내 출석 현황·출석률만 보임(다른 학생 없음)
  - [ ] 공지: 전체 공지 + 내 분반 공지만 보임, 작성 버튼 없음
  - [ ] Q&A: 질문 작성·수정·삭제(내 글만) / 답변 작성 / 내 답변 수정·삭제, 남의 답변에는 버튼 없음
  - [ ] 보관된 분반(지난 학기)이 "지난 소속"으로 보이고 기록 열람만 됨

- [ ] 목록에 번호·제목·태그·출제 횟수·**내 해결 표시**
- [ ] 번호 또는 제목으로 검색됨
- [ ] 태그 필터: 1개 고르면 그 태그 문제만 / **2개 고르면 둘 다 가진 문제만** / "필터 해제"로 복귀
- [ ] 문제 상세: 본문 · (자동 채점 문제면) **공개 예시**와 시간·메모리 제한
- [ ] **풀이 제출**: 언어 선택 + 코드 작성 → 제출 → "채점 중" → 판정
- [ ] 내 제출 기록: 최신이 위, 행을 누르면 채점 결과 + 코드 전문이 펼쳐지고 다시 누르면 접힘
- [ ] 맞히면 목록·상세에 **해결 표시**가 붙음
- [ ] **채점 기준(테스트케이스)이 없는 문제**: 제출란 대신 "운영진이 등록하면 풀 수 있어요" 안내
- [ ] **연습 제출은 과제와 섞이지 않음**: 같은 문제가 과제로도 배정돼 있을 때, HOJ 에서 푼 것이 과제 "내 제출 기록"이나 현황판에 나타나지 않음
- [ ] 수강생 화면에는 "문제 출제" 버튼과 문제 수정·삭제 버튼이 **없음**
- [ ] 분반에 소속되지 않은 부원도 목록·상세·풀이가 됨
