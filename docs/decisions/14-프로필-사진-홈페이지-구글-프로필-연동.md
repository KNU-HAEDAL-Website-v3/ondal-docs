# 14. 프로필 사진 - 홈페이지(구글) 프로필을 로그인 때 받아 온다, 업로드 없음

- 날짜: 2026-09-20 · 상태: 확정 · 결정자: PM
- 관련: [screens/my-page.md](../screens/my-page.md) · [db/schema.md](../db/schema.md) V12 · [결정 7](7-%ED%99%88%ED%8E%98%EC%9D%B4%EC%A7%80-sso-keycloak-oidc-be-%EC%BD%94%EB%93%9C-%EA%B5%90%ED%99%98.md) OIDC

## 배경

- PM: "피그마 마이페이지에 프로필 사진 등록이 있었던 것 같다" → 디자인 자료를 전수 확인(docs `design` 브랜치 zip 3종 = `docs/screens/ui-v1` 11장 동일). **마이페이지 화면은 없음**, 대신 원안 상단 바(수강자 홈·교육운영진 홈·관리자 개요)에 **실제 사진 아바타 + 이름 + 드롭다운(˅)** 이 있음
- 지금 구현은 이름 첫 글자 원형 + 이름 링크뿐 - 원안과 다른 부분은 여기

## 결정

- 상단 바(`AppShell`)를 원안대로: 사진 아바타 · 이름 · 드롭다운(마이페이지 · 로그아웃). HOJ 상단 바·마이페이지 헤더도 같은 아바타 부품(`UserAvatar`)
- **사진 출처는 홈페이지(구글) 프로필** - Keycloak OIDC ID 토큰의 `picture` 클레임을 로그인마다 받아 `users.avatar_url`(V12, 500자) 에 적는다. 없으면 null → 이름 첫 글자
  - Ondal 에 업로드 화면을 두지 않는 이유: 저장소·용량·삭제·부적절 이미지 관리가 통째로 생기는데, 부원은 이미 구글 계정으로 로그인하므로 사진이 거기 있다. 신원의 원본은 홈페이지(결정 7)라는 원칙과도 같다
  - 안전장치: `https://` 로 시작하는 500자 이하만 저장, `<img referrerPolicy="no-referrer">`, 못 불러오면 첫 글자로 대체
- 마이페이지 본문은 재설계본(FE #80) 유지 - 원안에 본문 화면이 없어 기준이 없고, 홈 문법으로 맞춘 현재 구성이 그 역할

## Keycloak 쪽 설정 (인프라, 1회) - 이것이 없으면 클레임이 없어 사진 없이(첫 글자) 동작

1. haedal realm → Identity providers → Google → Mappers → Add mapper: Mapper type **Attribute Importer**, Claim `picture`, User Attribute Name `picture`, Sync mode `force`(로그인마다 갱신)
2. Clients → `ondal-be` → Client scopes → `ondal-be-dedicated` → Add mapper → By configuration → **User Attribute**: User Attribute `picture`, Token Claim Name `picture`, Claim JSON Type String, Add to ID token ON
3. 확인: 구글로 재로그인 → Ondal 상단 바에 사진. (기존에 로그인만 했던 계정은 다음 로그인 때 채워짐)

## 검증

- BE `OidcAuthApiTest`: `picture` 클레임이 있으면 `/api/auth/me` 의 `avatarUrl`, 없으면 null 유지, `https://` 가 아니면 무시
- FE mock: `student1` 은 사진(`/favicon.svg`), 나머지는 첫 글자. 상단 바 드롭다운에서 마이페이지·로그아웃
