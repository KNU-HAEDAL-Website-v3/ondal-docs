# 13. HOJ P3 개방 - 랭킹 · 풀이 공개 · 채점 현황 · 정답 코드 · 편의 기능

- 일자: 2026-09-20 (PM)
- 상태: 확정
- 계약: [hoj/api.md](../hoj/api.md)

## 결정

- **P3(리더보드·티어) 유보를 해제**하고 HOJ 를 백준 문법으로 확장한다 - "그냥 P3 다 해버리자"
- 랭킹: 푼 문제 수 기준, 전체 + 분반 필터. 점수·티어는 두지 않음(푼 문제 수만)
- 다른 사람 풀이: **그 문제를 맞힌 사람만** 열람 (운영진 이상은 항상). 연습 제출만, 사용자당 최신 정답 1건
- 채점 현황(전체 제출 피드): **HOJ 연습 제출만** - 분반 과제 제출은 섞지 않는다
- 정답 코드: 문제마다 **언어별 참고 풀이**를 서버에 저장하고 운영진 이상에게 "정답 코드 보기"로 보여준다. 문제 은행 레포의 `solutions/sol.*` 를 가져오기 때 함께 읽는다. 학생에게는 존재도 보이지 않는다
- 나머지 편의 기능은 Claude 재량으로 같이 넣는다: 사용자 페이지(통계·푼 문제·잔디·태그 숙련도), 문제별 통계(푼 사람·제출·정답률)·내 상태 필터·북마크·랜덤 문제, 코드 템플릿·마지막 언어 기억·Ctrl+Enter·다시 편집, 내 입력으로 실행, 편집기 설정(글꼴·탭)
- 이번에 넣지 않는 것: 문제집(단계별 코스 - 운영진 큐레이션 데이터 필요), 문제별 토론(Q&A 스코프 확장 필요), 대회, 재채점 UI

## 왜

- 부트캠프 실사용(9/28) 전에 "풀고 → 결과 보고 → 남과 비교하고 → 남의 풀이에서 배우는" 순환이 있어야 HOJ 가 쓰인다. 지금은 풀고 내 기록만 본다
- 랭킹은 푼 문제 수 하나로 - 점수·티어를 붙이면 채점 기준 논쟁이 생긴다 (결정 4·mvp-scope 의 "점수 없음"과 충돌하지 않게 "개수"만)
- 풀이 공개는 표절 우려가 있어 **맞힌 뒤에만** - 백준·프로그래머스와 같은 규칙
- 정답 코드는 운영진이 채점 설정·질문 답변 때 참고하는 용도 - 학생 노출은 풀이 공개 규칙과 충돌하므로 금지

## 영향

- BE: V11(`problem_solutions`, `problem_bookmarks`), 엔드포인트 7종 신설·2종 확장, 가져오기가 `solutions/` 를 읽음, 실행 엔드포인트 학생 개방(분당 10회)
- FE: HOJ 메뉴 5개(문제·채점 현황·랭킹·내 페이지·태그 관리), 화면 3개 신설, 목록·상세·폼·마이페이지 확장
- 문제 은행: `tools/build.py` 가 정답 코드를 번들에 포함 (비공개 레포 → 서버 → 운영진만 열람)
- 권한표(permissions.md): 정답 코드 GET/PUT = 운영진 이상, 다른 사람 풀이 = 맞힌 사람·운영진, 그 외 신규는 로그인 누구나

## 재검토 조건

- 랭킹이 경쟁을 과열시켜 부정행위(풀이 복붙)가 보이면 → 풀이 공개를 운영진 전용으로 되돌리거나 분반 안에서만 공개
- 실행 엔드포인트 남용(Judge0 부하) → 한도 하향 또는 운영진 전용 복귀
