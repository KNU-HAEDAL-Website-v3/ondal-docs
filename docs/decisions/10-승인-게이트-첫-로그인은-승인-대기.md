# 10. 승인 게이트 - 첫 로그인 계정은 승인 대기, 운영진 승인·분반 배정으로 활성화

- 날짜: 2026-09-19 · 상태: 확정 · 결정자: PM
- 관련: [permissions.md](../permissions.md) "승인 대기" 절 · [db/schema.md](../db/schema.md) V8 · [flows-and-usecases.md](../flows-and-usecases.md) 3절-10(회원가입 방식) 해소 · BE ondal-BE #50 · FE ondal-FE #72

## 결정

- **홈페이지(구글) 로그인만으로는 Ondal 화면에 들어올 수 없다** - 운영진 측이 "부원"임을 확인한 뒤에만 열린다
- `users.status` (V8): `PENDING`(승인 대기) / `ACTIVE`. 되돌림 없음
  - 홈페이지(OIDC) 첫 로그인으로 생긴 계정 → PENDING
  - 명부 선등록(수강생 배정·운영진 지정으로 만들어진 계정)·스텁 로그인(local·test)·부트스트랩 관리자 → ACTIVE
  - 이미 있던 계정의 상태는 로그인이 건드리지 않는다 (이름만 홈페이지 값으로 갱신)
- 대기 중인 계정이 할 수 있는 것: `GET /api/auth/me`(자기 상태 확인)·로그아웃뿐. 나머지 전부 **403 `USER_PENDING`** - 권한 부족(`FORBIDDEN`, 홈으로)과 코드를 나눠 FE 가 "승인 대기" 화면을 그린다
- **승인 권한 = 해구르르 또는 어느 분반이든 교육운영진** (`@OperatorAnywhere`, PM 확정 "안 B")
  - `GET /api/users` 부원 목록(소속 요약 포함, 승인 대기 먼저) · `POST /api/users/{id}/approve` (멱등)
- **배정 = 승인**: 수강생 배정·운영진 지정 때 대기 계정이면 함께 ACTIVE - 분반에 넣는 행위가 곧 "우리 교육생" 확인이라 승인 버튼을 두 번 누르지 않는다. 승인만 하고 배정하지 않는 것(HOJ 만 쓰는 부원)도 가능
- FE: `RequireAuth` 가 `me.status === 'PENDING'` 이면 어느 주소에서든 대기 화면(이름·로그인 아이디·"다시 확인"·로그아웃)만. 운영진 홈 상단에 "승인 대기 N명" 배너 → `/members`(부원 관리, 대기 탭)
- 알림은 두지 않는다(2026-09-14 확정) - 학생은 "다시 확인" 버튼으로, 운영진은 홈 배너로

## 왜

- 구글 로그인은 "구글 계정이 있다"만 증명한다 - 해달 부원인지는 운영진만 안다. 승인 없이 열면 분반 목록·전체 공지·HOJ 가 아무에게나 보인다
- 운영진까지 승인 권한을 준 이유: 부트캠프 첫날 수십 명이 한꺼번에 로그인하는데 해구르르 혼자면 병목. 승인은 "부원 확인" 수준이라 분반 배정과 같은 신뢰 수준이다
- 배정을 승인으로 치는 이유: 운영진의 실제 작업은 "명부 짜기"다. 그 작업 안에서 승인이 끝나야 두 화면을 오가지 않는다
- 판정 위치를 `AuthorizationInterceptor`(①로그인 다음, ②③④역할 전)에 둔 이유: 이미 매 요청 사용자를 읽는 자리라 쿼리가 늘지 않고, 역할이 있어도(예: 선등록 없이 로그인한 임원) 승인 전엔 막힌다

## 기각한 대안

| 안 | 기각 사유 |
|---|---|
| 해구르르만 승인 (안 A) | 첫날 병목. 운영진이 명부를 짜다 말고 해구르르를 기다려야 함 |
| 승인 없이 배정만으로 활성화 | HOJ 만 쓰는 부원·미소속 부원의 전체 공지 열람 경로가 없어짐 |
| 구글 Workspace 도메인(hd 클레임) 자동 승인 | 학교 계정이 아닌 부원이 있고, 학교 도메인이 곧 부원을 뜻하지도 않음. 나중에 **보조 규칙**으로 검토 가능 |
| Keycloak 콘솔에서 관리자가 계정을 직접 만들기(기존 3절-10) | 구글 로그인 도입으로 계정은 스스로 생김 - 관리자가 할 일은 "확인"만 남는다 |

## 남는 것

- 차단(BLOCKED) 상태는 두지 않았다 - 필요해지면 상태를 늘리고 인터셉터의 같은 자리에서 막는다
- 3절-10 회원가입 방식: **해소** - 홈페이지 구글 로그인(자율 가입) + Ondal 승인 게이트
